# TEKTON Sprint 3 acceptance checklist

## Company onboarding preview
- Open Company Setup as an internal demo role.
- Enter a fictional company, select modules and approval threshold, then save the preview.
- Confirm the saved preview survives reload, and reset restores defaults.
- Client Representative must not see the company setup or sample reporting modules.

## Documents and project reports
- Browse Documents: metadata-only original entries plus fictional PO, variation and site record summaries.
- Open an example. Check project name, revision, date, status and traceability.
- Download a clearly marked fictional .txt summary.
- Use the browser's print / Save as PDF option for a printable record.
- Open Sample Reports and compare approved project costs, site progress, schedule and changes to current demo data.
- No real source files, signed contracts, engineering certificates or accounting statements are present.

## Pilot enquiry
- Open /pilot/ from the homepage, application sidebar or footer.
- Check form field validation, prepared draft, copy action, and email composer.
- The form must never claim successful delivery. There is no configured inbox, external lead database or transport endpoint.
- Editing prepared fields clears the stale draft.

## Responsive QA and regression
- Visually inspect viewports 360, 390, 768, 1024, 1440 pixels.
- Check mobile tables, header select controls, tab navigation, inputs, and print styles.
- Verify existing procurement and variation workflows retain stage controls and browser persistence.
- Verify all static routes and brand SVGs return HTTP 200.

## Release notes
This is a static fictional-data demonstration, not secure SaaS. Server-side identity, tenant isolation, file storage, lead intake and payments still require production implementation.
