# TEKTON — Brand Identity Kit v1.0

**Brand direction approved:** 21 November 2026.  
**Status:** Editable visual identity system; TEKTON remains a provisional name pending legal clearance.

## Positioning

**TEKTON — The Operating System for Construction.** Construction software designed to connect project delivery, procurement, people, and costs through one operating environment.

**Brand character:** Structured · Reliable · Precise · Modern. Quietly premium, never flashy.

## Source artwork

- `logos/svg/` contains editable light, dark, tagline and monochrome SVG lockups.
- `icons/svg/` contains standalone marks and app-icon variants.
- `tokens/tekton.css` and `tokens/tekton.tokens.json` contain authoritative digital colours and system values.
- `tokens/tekton-color-codes.csv` contains RGB and approximate CMYK values.
- `guidelines/` contains logo, voice and typography guidance.
- `templates/` contains practical brand templates for proposals, email and social marketing.

## Brand palette

| Name | HEX | Usage |
|---|---|---|
| Charcoal | `#1F1F1F` | Wordmark, headings, primary controls, dark backgrounds |
| Slate | `#3A3A3A` | Dark surfaces and secondary structure |
| Graphite | `#6B6B6B` | Muted text (check contrast) |
| Ash | `#D4D4D4` | Quiet visual panels, never body text |
| Concrete White | `#F5F5F2` | Main light background |
| Surface | `#E9E9E7` | UI surfaces |
| Border | `#DADADA` | Borders and dividers |
| White | `#FFFFFF` | Reverse marks and cards |

## Logo usage

- Light background: `logos/svg/tekton-primary-light.svg`.
- Dark background: `logos/svg/tekton-primary-dark.svg`.
- Allow at least 25% of the symbol width as clear space.
- Minimum recommended horizontal size: 140 px on-screen, 30 mm print. Symbol: 24 px.
- No stretching, rotation, colour alterations, bevels, shadows, or glow.
- Use Inter (fallback Arial). **Do not commit font files to the repository.**

## Accessibility

- Charcoal on Concrete White: approximately 15.1:1 contrast.
- Graphite on Concrete White: approximately 4.9:1.
- Ash on white: ~1.5:1, not suitable for text.

## Handoff

These assets are independent of the current live site; merely adding the kit does **not** switch the website/demo palette. When rebranding, import shared tokens and replace logo assets in both the landing page and `/demo/`, then deploy and verify.

## Legal caveat

The product name **TEKTON** has potential marketplace naming conflicts; secure professional construction-software trademark and domain clearance before commercial use. Do not display trademark registration marks unless legally appropriate.
