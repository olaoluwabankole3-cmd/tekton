# TEKTON — Construction Operating System

White-label construction software product website and interactive sandbox demonstration.

## Routes

- `/` — public product landing page
- `/demo/` — interactive demo with fictional data

## Preview

Serve the repository root as a static website. No build command is required.

## Scope

The demo uses fictional construction records and browser-local state. It is not a production multi-tenant platform; authentication, payments, and persistent backend are not yet integrated.

## Naming

TEKTON remains a provisional working name pending trademark clearance.

## Brand identity

The approved charcoal/ash TEKTON identity is archived in [`brand/`](brand/README.md), including vector marks, exact palette codes, design tokens and usage guidelines. The website and demo have not yet been visually migrated to the new kit.
